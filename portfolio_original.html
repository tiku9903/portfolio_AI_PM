n8n

Self-hosted, open-source workflow automation. I use it for complex multi-step pipelines where data privacy matters or where API costs need control. Runs LLM nodes natively.

LangGraph

Framework for stateful, multi-agent reasoning graphs. Used when tasks require memory, conditional branching between agents, or retry logic — like healthcare triage systems.

Make.com

Visual scenario-based automation. Best for client-facing systems where non-technical teams need to understand and modify workflows. Strong API + SaaS connector library.

OpenAI / Claude APIs

Core LLM inference layer. GPT-4o for classification + generation tasks; Claude for long-document reasoning and nuanced instructions. Prompt-engineered, not fine-tuned by default.

Zapier

Rapid deployment for SaaS-heavy stacks. Best when the client already lives in tools like HubSpot, Slack, or Gmail and needs fast, no-code trigger-action automation without infrastructure overhead.

Airtable

Relational data backend for automation systems. Acts as the operational database — storing leads, tickets, logs — while connecting cleanly to n8n, Make, and Zapier via API.

Beacon Pulse: AI-Powered Customer Service Automation

The Problem

Beacon Lighting's customer support operation had grown into 4 fragmented teams — Customer Support, Warranty, Technical, and Returns — with no shared system and $2.2M in annual labour and overhead costs. With 40,000 tickets/year processed manually, response time averaged 12 hours, and there was zero after-hours capability. The trade division (B2B customers) was highest-value but received no priority treatment. Manual operations meant cost grew proportionally with volume — every new trade contract required new headcount.

The Solution
  • Unified all channels (email, web form, live chat) into a single intake queue
  • NLP engine (BERT + TensorFlow) classifies intent, extracts entities, scores urgency, and runs safety scans on every ticket
  • ML classifier routes to the right agent queue — including instant VIP routing for trade customers
  • 60% of tickets auto-resolved (order status, standard FAQs, warranty checks via Magento + Customer 360 integration)
  • 30% AI-drafted with human review — agents edit, not write from scratch
  • Escalation keywords trigger immediate safety alerts; humans sign off all refunds
  • 24/7 coverage through always-on automation — no overnight backlog

The Problem

Real estate agents were losing 6–10 hours per week per person to qualification calls — asking the same questions (timeline, budget, pre-approval status) to leads who were mostly not ready. The few ready leads were being reached too slowly. Speed-to-lead is the single biggest predictor of conversion, and it was consistently breaking. SDR costs were $4–6K/week with high burnout and inconsistent script execution. The pipeline was leaky: good leads fell through while agents were stuck on bad ones.

The Solution
  • Voice AI agent auto-dials leads within seconds of entering the CRM — from any source (ads, web form, list import)
  • Conversational qualification in natural language — not a robocall or IVR tree
  • Captures timeline, budget range, and pre-approval status during the call
  • Books qualified leads directly onto the agent's calendar; sends SMS confirmation; alerts the human agent
  • Parallel scale — can run hundreds of simultaneous calls with identical script discipline
  • Every call is logged, scored, and reviewable — insight loop for continuous improvement
  • Agents now speak only to leads who have already confirmed readiness to transact

Multi-Agent Healthcare Pipeline (LangGraph)

5-agent conditional graph for full clinical workflow — X-ray triage through nearest pharmacy matching

Architecture

Built a full agentic pipeline using LangGraph where each agent has a single, well-scoped responsibility. The Ingestion Agent extracts structured patient data. The Imaging Agent classifies chest X-rays (normal / pneumonia / COVID-suspect). Routing logic decides: severe or low SpO₂ → Doctor Escalation Agent; mild → Therapy Agent. The Therapy Agent filters OTC recommendations against age restrictions, allergy conflicts, and drug-drug interactions before suggesting medicines. The Pharmacy Agent geo-matches (haversine formula) the nearest pharmacy with live stock, ETA, and total cost.

Key Engineering Decisions
  • LangGraph conditional graph — not a linear chain — ensures proper branching based on real severity data
  • Safety-first therapy suggestions: checks 3 safety layers before any medicine recommendation
  • Independent pytest modules for each agent — ensures reliability at agent level, not just system level
  • Streamlit frontend makes the entire pipeline interactive and auditable by non-technical users
  • Designed for real API integration (live doctor availability, live pharmacy stock) as next milestone
  • This project is a direct precursor architecture for real-world clinical triage automation
